# pkgbuilds-personal

Personal Arch Linux and CachyOS packages for one AMD Ryzen 5 5600X3D / ASUS TUF
GAMING B550-PLUS WIFI II workstation and its companions: memory and swap policy,
sensor configuration, crash forensics, shell, git and editor configuration,
desktop ricing and small hardware tools. None of these has an upstream release;
each configuration value is documented with the measurement that justifies it.

Hardware and the evidence behind each setting: [docs/SYSTEM.md](docs/SYSTEM.md).
Rules: [AGENTS.md](AGENTS.md). Origin of each recipe: [PROVENANCE.tsv](PROVENANCE.tsv).
